# Security Policy

## Supported versions

Security fixes are provided for the latest stable release.

## Reporting a vulnerability

セキュリティ上の問題には、認証情報、個人情報、生ログ、完全なBluetoothデバイスIDを含めず、GitHubの**Security**タブにある**Report a vulnerability**から非公開で報告してください。公開Issueへ脆弱性の詳細を投稿しないでください。

Please report vulnerabilities privately through **Security → Report a vulnerability** on GitHub. Do not include credentials, personal information, raw logs, or complete Bluetooth device IDs, and do not disclose vulnerability details in a public issue.
