# Phone Audio Receiver

スマートフォンのBluetooth音声をWindows PCで受信し、Windowsの既定の再生デバイスから再生するアプリです。

## 動作環境

- 64bit版 Windows 10 バージョン2004以降、または Windows 11
- Bluetooth機能
- 音声再生に対応した、ペアリング済みのスマートフォン
- Microsoft Edge WebView2 Runtime
  - 通常の Windows 10 / 11 にはあらかじめ導入されています。
  - 起動時に画面が表示されない場合のみ、Microsoft公式サイトから「Microsoft Edge WebView2 Runtime」を導入してください。

## 使い方

1. このフォルダーを任意の場所へ展開します。
2. `Phone Audio Receiver.exe` を実行します。
3. アプリで **再検索** を押します。
4. 表示されたスマートフォンの **接続** を押します。
5. スマートフォンで音声を再生します。音声はWindowsの既定の再生デバイスから出力されます。

アプリを閉じても、既定では終了せずタスクトレイへ格納されます。タスクトレイのアイコンをクリックすると再表示できます。完全に終了する場合は、タスクトレイのアイコンを右クリックして **終了** を選んでください。

タスクトレイを左クリックすると、最後に閉じた通常画面またはクイック操作画面が復帰します。右クリックメニューには、トレイ固定、接続中・接続処理中、お気に入り、その他の端末の順で最大6台が表示され、各グループ内では設定した表示順を維持します。端末ごとに接続・切断でき、7台以上見つかった場合は、**その他の端末…**から全端末を扱えるクイック操作画面を開けます。

通常画面では、星でお気に入り、ピンでトレイ固定、鉛筆でアプリ内の表示名、上下矢印で共通の表示順を設定できます。時計のメニューから、接続中の端末だけを15分、30分、1時間、2時間後に切断するタイマーも設定できます。接続、切断、タイマーは表示順ではなく対象端末のBluetoothデバイスIDに対して実行します。

アイコンとキーボード操作は、右上の **…** → **操作方法** で確認できます。**F5**で再検索、**Alt+Q**で通常画面とクイック操作画面の切り替え、クイック操作画面では**Ctrl+F**で検索欄へ移動できます。

## 困ったとき

- **端末が表示されない**: WindowsのBluetooth設定でスマートフォンがペアリング済みか確認してから、アプリで再検索してください。
- **起動しても画面が出ない**: WebView2 Runtimeの導入を確認してください。
- **接続できない／音声が出ない**: Bluetoothを一度オフ・オンにし、スマートフォン側のBluetooth接続も確認してください。再生先はWindowsの既定の再生デバイスです。
- **スマートフォン側で切断した後も「接続中」と表示される**: 対象端末の「切断」を押してアプリ内の接続を解除してから、改めて「接続」を押してください。
- **詳しい状況を確認したい**: アプリ右上の **…** → **アプリログ** から匿名化した直近の記録を確認し、「匿名化済みログをコピー」で共有できます。必要なら「生ログフォルダーを開く」から `log.txt` を確認できますが、生ログには端末名、完全なBluetooth ID、ユーザーフォルダーが含まれる場合があるため、そのまま第三者へ共有しないでください。ログが2MBに達すると、直前の内容は `log.previous.txt` に移されます。

設定とログは次のフォルダーに保存されます。

```text
%APPDATA%\phone_audio_receiver\
```

初回起動時の表示言語はWindowsの優先表示言語に従います。画面右上で日本語または英語へ
切り替えると、選択した言語を次回起動後も保持します。

## 制約

- 出力先はWindowsの既定の再生デバイスです。本アプリから個別の出力デバイス指定はできません。
- 端末ごとの音量・ミュート操作はできません。Windowsの音量ミキサーまたはスマートフォン側で調整してください。
- 外部切断後の自動再接続機能は、Windows APIによる切断状態の誤判定を避けるため提供していません。スマートフォン側やBluetooth側から切断した場合、画面表示が自動更新されないことがあります。設定の「起動時に選択した端末へ自動接続する」は、アプリ起動時だけ動作する別機能です。
