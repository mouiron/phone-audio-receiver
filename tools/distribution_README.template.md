# Phone Audio Receiver

スマートフォンのBluetooth音声をWindows PCで受信し、Windowsの既定の再生デバイスから再生するアプリです。

バージョン: {{VERSION}}

## インストール

1. GitHub Releasesから`Phone Audio Receiver {{VERSION}} (Windows x64)-setup.exe`をダウンロードします。
2. Releaseに記載されたSHA-256と、ダウンロードしたインストーラーのSHA-256が一致することを確認します。
3. インストーラーを実行します。
4. Microsoft Defender SmartScreenが表示された場合は、配布元とSHA-256を確認し、信頼できる場合にだけ **詳細情報** → **実行** を選んでください。

インストーラーはすべてのWindowsユーザー用として`Program Files`配下へインストールされます。インストールとアンインストールには管理者権限が必要です。

## 動作環境

- 64bit版 Windows 10 バージョン2004以降、または Windows 11
- Bluetooth機能
- 音声再生に対応した、ペアリング済みのスマートフォン
- Microsoft Edge WebView2 Runtime
  - 通常の Windows 10 / 11 にはあらかじめ導入されています。
  - 起動時に画面が表示されない場合のみ、Microsoft公式サイトから「Microsoft Edge WebView2 Runtime」を導入してください。

## 使い方

1. スタートメニューから **Phone Audio Receiver** を起動します。
2. アプリで **再検索** を押します。
3. 表示されたスマートフォンの **接続** を押します。
4. スマートフォンで音声を再生します。音声はWindowsの既定の再生デバイスから出力されます。

アプリを閉じても、既定では終了せずタスクトレイへ格納されます。タスクトレイのアイコンをクリックすると再表示できます。設定で「閉じる時にタスクトレイに格納する」をオフにした場合は、通常画面の×ボタンでアプリ全体を終了します。完全に終了する場合は、タスクトレイのアイコンを右クリックして **終了** を選ぶこともできます。

タスクトレイを左クリックすると、最後に閉じた通常画面またはクイック操作画面が復帰します。右クリックメニューには優先度順で最大6台が表示され、端末ごとに接続・切断できます。7台以上見つかった場合は、**その他の端末…**から全端末を扱えるクイック操作画面を開けます。

## アンインストール

1. タスクトレイのPhone Audio Receiverを右クリックし、**終了**を選んで完全に終了します。
2. Windowsの **設定** → **アプリ** → **インストールされているアプリ** を開きます。
3. **Phone Audio Receiver** のメニューから **アンインストール**を選び、画面の案内に従います。

アンインストールすると、アプリ本体、ショートカット、アンインストールを実行したWindowsユーザーのログオン時の自動起動登録が削除されます。設定とログは、再インストール時に引き継げるよう次のフォルダーへ残します。

```text
%APPDATA%\phone_audio_receiver\
```

設定とログも完全に削除する場合は、アンインストール完了後に上記フォルダーを手動で削除してください。生ログには端末名、完全なBluetooth ID、ユーザーフォルダーが含まれる場合があるため、削除前に第三者へ共有しないでください。

## 困ったとき

- **端末が表示されない**: WindowsのBluetooth設定でスマートフォンがペアリング済みか確認してから、アプリで再検索してください。
- **起動しても画面が出ない**: WebView2 Runtimeの導入を確認してください。
- **接続できない／音声が出ない**: Bluetoothを一度オフ・オンにし、スマートフォン側のBluetooth接続も確認してください。再生先はWindowsの既定の再生デバイスです。
- **スマートフォン側で切断した後も「接続中」と表示される**: 対象端末の「切断」を押してアプリ内の接続を解除してから、改めて「接続」を押してください。
- **詳しい状況を確認したい**: アプリ右上の **ログ** から匿名化した直近の記録を確認し、「匿名化済みログをコピー」で共有できます。必要なら「生ログフォルダーを開く」から `log.txt` を確認できますが、生ログには端末名、完全なBluetooth ID、ユーザーフォルダーが含まれる場合があるため、そのまま第三者へ共有しないでください。ログが2MBに達すると、直前の内容は `log.previous.txt` に移されます。

設定とログは次のフォルダーに保存されます。

```text
%APPDATA%\phone_audio_receiver\
```

アプリの表示言語はWindowsの優先表示言語に従い、日本語または英語になります。

## 制約

- 出力先はWindowsの既定の再生デバイスです。本アプリから個別の出力デバイス指定はできません。
- 端末ごとの音量・ミュート操作はできません。Windowsの音量ミキサーまたはスマートフォン側で調整してください。
- 外部切断後の自動再接続機能は、Windows APIによる切断状態の誤判定を避けるため提供していません。スマートフォン側やBluetooth側から切断した場合、画面表示が自動更新されないことがあります。設定の「起動時に選択した端末へ自動接続する」は、アプリ起動時だけ動作する別機能です。
